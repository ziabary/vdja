# Branding Agent Instructions

Inherit `/AGENTS.md`.

Owns runtime visual/product identity configuration only.

## Required

- Support product/org identity, logo/favicon, tokens, typography, login/email/notification/support/footer/legal/document branding.
- Prefer runtime/deployment replacement.
- Expose only safe public branding config.
- Keep `@targoman/*` code identity separate from runtime BrandProfile identity; FAPA assets/names are selected only by an active FAPA profile.

## Forbidden

- Secrets.
- Business semantics.
- Hard-coded customer/Targoman identity in business modules.
