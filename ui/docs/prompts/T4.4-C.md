====================================================================
4. DEFINITION — blocksT5Start
====================================================================

Set:

blocksT5Start = true

ONLY if the unresolved control concerns a security foundation that T5 MUST trust
before Document/RAG code is written.

A control blocks T5 start when its absence would cause T5 to be built on an
incorrect security architecture or require a fundamental security rewrite.

Typical PRE-T5 foundations include:

- canonical Identity;
- canonical Session;
- tenant isolation;
- Authority sole ownership;
- generic persisted Authority correctness;
- object authorization;
- field authorization;
- ACL;
- classification / clearance;
- ownership / scopes;
- authorization invalidation;
- originating-subject preservation;
- unavoidable Authority decision Audit;
- Audit integrity;
- canonical SIEM pipeline;
- persistence ownership;
- Configuration / secretRef architecture;
- AI Router ownership;
- current file-ingress/parser safety;
- architecture guardrails.

Do not mark a control blocksT5Start merely because it is generally important to
security.

====================================================================
5. DEFINITION — verifyDuringT5
====================================================================

Set:

verifyDuringT5 = true

when the control can only be meaningfully verified after T5 introduces or
changes the relevant surface.

Examples include controls concerning:

- Document Core;
- Document Version;
- Document Asset;
- File Management;
- upload/download lifecycle;
- S3;
- storage caching;
- signed download/upload;
- Qdrant;
- embeddings;
- reranking;
- retrieval;
- RAG context construction;
- citation;
- quote;
- Data Governance;
- protected model egress;
- document retention;
- document cache;
- RAG-specific sensitive data;
- RAG-specific resource exhaustion;
- RAG-specific logs/Audit;
- new authenticated RAG UI.

Such controls MUST NOT block starting T5.

They become mandatory acceptance controls inside T5.

8. T5-CREATED SURFACE MUST NOT CREATE A CIRCULAR GATE
====================================================================

on functionality that T5 itself must implement.

RAG cache controls cannot be proven before File Management exists.

Such controls belong to:

verifyDuringT5 = true

and normally:

blocksCustomerRelease = true.
