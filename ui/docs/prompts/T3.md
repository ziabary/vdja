# Task T3 — Anonymous Public Product Runtime
# PostgreSQL Migration, Audit, Usage, Admission Control, SIEM Push,
# White-Label Deployment and MySQL Independence

T2 established the PostgreSQL persistence foundation.

U2/U2.1 established working Svelte frontends and live parity for:

- Translator
- Summarizer
- FAQ Generator

They currently still depend on the legacy Express/MySQL backend path.

T3 converts these three public anonymous services into the first
production-capable target-platform deployment.

At the end of T3:

- Translator works without MySQL.
- Summarizer works without MySQL.
- FAQ Generator works without MySQL.
- PostgreSQL is the only relational database required by these three services.
- Required legacy MySQL reference data has been migrated and verified.
- Anonymous requests are fully accounted, audited and observable.
- Admission Control is active before expensive AI/file work.
- SIEM push export is operational and durable.
- customer branding is runtime/deployment configurable.
- deployments may enable any one, any two, or all three modules.
- no Login, Session, JWT or human Identity is required.
- the product can be deployed to a customer as an anonymous-only branded service.

This is a production vertical slice, not a mock or foundation-only task.

Do not start CRM, RAG, Identity, Session or Authority implementation.
