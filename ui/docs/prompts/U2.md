# Task U2 — Public AI Tools Migration

Migrate the three existing public, unauthenticated AI tools from the legacy frontend to the new SvelteKit target frontend:

```text
Translator
Summarizer
FAQ Generator
```

This is the first real production-feature migration onto the new Svelte foundation.

The backend is **frozen for this task**.

The objective is:

> Reproduce the existing public-tool behavior in SvelteKit against the same existing backend contracts, prove parity, cut the routes over, and only then remove the corresponding legacy frontend implementations.

Do not migrate authenticated modules.

Do not modify backend behavior.

Do not redesign APIs.

Do not touch database architecture.

Do not begin Identity/tenant work.
