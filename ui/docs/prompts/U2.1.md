# Task U2.1 — Existing API Bring-up, Live Parity, Cutover & Legacy Frontend Retirement

U2 implemented candidate SvelteKit replacements for the three public anonymous AI tools:

```text
Translator
Summarizer
FAQ Generator
```

Current U2 status is intentionally PARTIAL because:

```text
candidate Svelte UI             = implemented
fixture/component/browser tests = passed
backend source changes          = none
live existing API               = unavailable
live parity                     = not proven
production cutover              = not performed
legacy frontend removal         = not performed
```

This task closes that gap.

The objective is:

> Bring up the existing backend and its existing runtime dependencies without changing backend behavior, exercise all three Svelte tools end-to-end against the real existing API, prove legacy-vs-Svelte parity, and only after every gate passes cut over those three public routes and retire only their exclusively owned legacy frontend files.
