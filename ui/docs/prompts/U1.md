# Task U1 — SvelteKit Foundation, Shared UI Packages & UI Guardrails

U0 and U0.1 define the approved FAPA target UI architecture.

This task implements the **target frontend foundation only**.

Do not migrate CRM, Widget, RAG, Secretariat or other business screens yet.

Do not cut production ingress to SvelteKit.

Do not delete legacy frontend files.

The objective is:

> Build a production-quality SvelteKit foundation whose architecture is correct before business-screen migration begins.

U1 must establish:

```text
target workspace/package structure
SvelteKit SSR application
shared UI packages
Calendar Core / Calendar Svelte
branding/theme/RTL foundation
typed module/chrome contribution contracts
API/auth/streaming interfaces
safe Markdown boundary
shared form/list/overlay primitives
UI-specific static guardrails
component/contract tests
target-tree zero-violation gate
```
