# Architecture Documentation Agent Instructions

Inherit `/AGENTS.md`.

Governing architecture is normative according to status/precedence.

## Required

- Preserve canonical terminology/ownership across documents.
- Update dependent docs when an invariant changes.
- Distinguish invariants from examples.
- Keep generic architecture free of customer-specific SLO/RPO/RTO values unless approved.
- Keep examples aligned with naming and target repository structure.
- Label legacy evidence vs target design explicitly.

## Forbidden

- Silent contradiction of higher-precedence documents.
- Changing target architecture merely to match legacy implementation.
