# U1.2 Showcase and Development

Status: implemented for automated review; human visual approval pending. This is a foundation preview, not a business screen or production route binding.

## Locale ownership

`packages/ui-core/src/i18n/index.ts` owns the small typed `fa`/`en` presentation dictionary and request-local Svelte context used by the Web shell, generic table and overlay labels, and Calendar Svelte. Persian is the default; `fa` maps to `rtl` and `en` to `ltr`. The server hook and layout load read the same `ui-locale` cookie before SSR, so the HTML root, Bootstrap direction asset, shell text, and hydration agree. The header locale selector writes that cookie and reloads. The context does not carry business semantics, authorization, backend errors, calendar arithmetic, or BrandProfile values. The current anonymous BrandProfile remains the neutral Workspace fixture.

## Showcase

At `http://localhost:5173/foundation` in development, 13 sections cover branding and shell, typography, Persian numerals, direction and visibility utilities, FontAwesome, all shared forms, Jalali date/date-time/range fields, cursor table, Markdown, feedback, overlays, AI state simulation, and a human visual checklist. Fixtures are local and synthetic. The AI controls call only the UI state machine. Form and calendar values show canonical serialized values separately from their Persian presentation. The table intentionally has no total count.

The server `+page.server.ts` calls `requireDevelopmentShowcase(import.meta.env.DEV)`. A normal production build returns 404 for `/foundation`; hiding links is not its access control. The home page may retain a development link, but the production route remains unavailable.

## Development commands and origin

Use Node 22.17+ for Web. From the repository root:

| Command | Behavior |
|---|---|
| `npm run dev` | Starts the Web preview on port 5173 using the normal root command |
| `npm run dev:web` | Web only, bound to `0.0.0.0:5173` |
| `npm run dev:api` | Existing Express `sdev` process only, normally `0.0.0.0:3000`; requires its configured database and services |
| `npm run sdev` / `npm run lint:watch` | Preserved legacy workflows |

The API is opt-in because the current legacy process requires an unavailable local database and logs sensitive configuration at startup. Do not treat a running watch process as an available API. Web uses a development-only `/api` proxy to the existing Express `/api` routes. Its default target is `http://127.0.0.1:3000`. `DEV_API_ORIGIN` may select another loopback HTTP port; non-loopback and credential-bearing origins are rejected. Browser API calls continue to use logical `/api` paths. The proxy forwards streaming responses through Vite's HTTP proxy without buffering in Web code. Production ingress and API routing are unchanged. The Express process may still need its existing local service configuration to serve real endpoints; the showcase itself needs none of those services.

## Calendar corrections

Month arrows now follow the effective direction: previous points right in RTL and left in LTR; next is the inverse. Home/End use `jalaliMonthGrid().offset` to find the first/last available day in the rendered week row. Arrow keys follow direction; PageUp/PageDown change Jalali month while retaining the day when possible. Escape closes and restores trigger focus. All built-in labels come from the locale context.

Date and range fields share the themed Jalali month component. A range uses one popover: the first day starts a draft interval, pointer hover previews it, and the second day completes it, including selection across adjacent months or in reverse order. Desktop shows two months and narrow screens show one. Canonical values remain Gregorian ISO dates. Popovers use viewport coordinates and clamp to the visible area; focusing a day does not scroll the page. Dialog and Drawer use native modal dialogs with viewport-bounded surfaces, internal content scrolling, focus restoration, and a reference-counted background scroll lock.

The month and year labels in each calendar header are buttons. The month button opens all twelve Jalali months. The year button opens a twelve-year page with page navigation and an exact-year field accepting Persian, Arabic, or Latin digits. Choosing either returns to the day grid, preserves a draft range, and respects the component's `min`/`max` bounds and Calendar Core's supported years.

The single-date calendar footer has a localized Today action in place of its static instruction. It selects the injected `today` date, emits the same canonical Gregorian value as a day click, closes the popover, and is disabled when today is outside `min`/`max`.

## Manual review

Start `npm run dev:web` or `npm run dev`, open `/foundation`, and use the checklist at the bottom. Inspect desktop and mobile widths, light/dark/system theme, Persian default and English cookie selection, calendar navigation with keyboard, Dialog/Drawer focus, and font loading in browser network tools. This procedure is for a human reviewer; passing automated checks does not mark visual approval.
