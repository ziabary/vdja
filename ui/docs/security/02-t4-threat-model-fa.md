# مدل تهدید T4

محدوده: وب SvelteKit، API، Worker، PostgreSQL، فایل، AI Router، SIEM، هویت جهانی و نشست وابسته به مستأجر. این سند وضعیت طراحی و خطرهای باز را ثبت می‌کند.

| تهدید | مسیر حمله | مرز و کنترل لازم | وضعیت |
| --- | --- | --- | --- |
| سوءاستفادهٔ ناشناس | درخواست انبوه ترجمه/خلاصه/FAQ | Admission پایدار، سقف ورودی/خروجی و حسابداری | آزمون زندهٔ سه ابزار و حدود N−1/N/N+1 گذشت؛ آزمون فشار باز |
| credential stuffing و شمارش حساب | تلاش ورود و تفاوت پاسخ | نرخ محدود پایدار، پاسخ یکسان، هش امن، رویداد امنیتی | guard پایدار، پاسخ عمومی و Audit/SIEM آزموده؛ اعلان مشکوک به کاربر باز |
| سرقت توکن و XSS | خواندن access token یا تزریق اسکریپت | توکن در حافظه، CSP، خروجی امن، عمر کوتاه | Chrome نبود توکن در storage/cookie و نگهداری حافظه را آزمود؛ بررسی کامل CSP/XSS باز |
| بازپخش refresh | استفادهٔ مجدد از توکن چرخیده | تراکنش اتمی PostgreSQL، ابطال خانواده، رویداد پرخطر | آزمون HTTP، PostgreSQL و Chrome برای مسابقه/بازپخش و Audit/SIEM گذشت |
| CSRF | ارسال درخواست کوکی‌دار از مبدأ بیگانه | SameSite، کنترل Origin، endpoint محدود refresh | Origin نامعتبر/غایب و preflight نامعتبر در HTTP رد شد؛ preflight مجاز فقط POST و headerهای تعیین‌شده را می‌پذیرد. ماتریس کامل CSRF و مبدأ اختصاصی باز است |
| cookie tossing | ارسال چند کوکی Refresh هم‌نام با مسیر/دامنهٔ متفاوت | رد ابهام پیش از گردش یا ابطال نشست | آزمون واحد و HTTP زنده، رد هر دو مسیر refresh/logout و بقای نشست معتبر را نشان داد؛ مرز host اختصاصی هنوز باز است |
| تعویض مستأجر و دسترسی متقاطع | جعل شناسه در header/claim و تجمیع نقش‌ها | نشست مستأجرمحور، بررسی membership، Authority، RLS مکمل | آزمون زندهٔ A/B/AB، header mismatch، grant غیرتجمیعی و RLS گذشت |
| مجوز کهنه و ارتقای اختیار | تغییر نقش بعد از صدور توکن؛ ALL بدون مرز | نسخهٔ مجوز، ابطال نشست، deny و مرز سخت | نسخهٔ مجوز، deny صریح و ALL با مرز مستأجر آزموده؛ دامنه/ACL/classification در مسیر تولیدی همه‌جانبه آزموده نشده |
| نشست آلوده یا fixation | نگه‌داشتن شناسهٔ نشست پیش از ورود | شناسهٔ تازه پس از ورود، revoke فوری، فهرست نشست | شناسهٔ تازه، خروج و رفتار Chrome آزموده؛ فهرست/ابطال نشست‌های دیگر باز |
| فایل مخرب | parser abuse، traversal و بمب فایل | File Processing، حد حجم/صفحه، جداسازی مسیر موقت | T3 موجود؛ آزمون بدخواهانه باز |
| خروجی LLM مخرب | دستور پنهان و HTML/Markdown خطرناک | خروجی غیرقابل‌اعتماد و render امن | آزمون امنیت UI باز |
| خرابی provider | timeout و نتیجهٔ نامعلوم | AI Router، مدار، fallback و عدم بازپخش خروجی قابل رؤیت | آزمون T3 موجود؛ موارد لبه باز |
| خرابی SIEM | پذیرش رویداد و گم‌شدن ACK | UNKNOWN پایدار؛ retry فقط با تضمین گیرنده | آزمون T3 گیرندهٔ HTTP و آزمون T4 Worker برای رویداد Auth/Authority/سه ابزار گذشت؛ آزمون خاموشی طولانی باز |
| نفوذ پایگاه داده | دستکاری رکورد/ممیزی و استخراج credential | حداقل اختیار، audit trigger، رمزگذاری/نگهداشت | آزمون دسترسی و بازیابی باز |
| سوءاستفادهٔ break-glass | دسترسی اضطراری بی‌دلیل/نامحدود | درخواست صریح، زمان/دامنه، MFA، تأیید و ممیزی | پیاده‌سازی T4 باز |

خطر انتشار: کوکی Refresh با مسیر محدود هنوز V3.3.3 را برآورده نمی‌کند؛ تصمیم سه‌گزینه‌ای در `03-t4-refresh-cookie-decision-fa.md` ثبت شده است. کوکی‌های غیرحساس تنظیمات Web اکنون `__Host-` و Secure هستند. تغییر/بازیابی گذرواژه، اتصال غربال گذرواژهٔ رایج به مسیر عملیاتی، عامل سخت‌افزاری مقاوم در برابر فیشینگ و اعلان تلاش مشکوک نیز باز هستند. ارزیابی ۳۳۵ کنترل ASVS هنوز تکمیل نشده است. بنابراین Auth در deployment مشتری منتشر نشود و `READY_FOR_RAG_SECURITY_GATE = NO` بماند.
