# تصمیم کوکی Refresh و ASVS V3.3.3

**وضعیت: تصمیم موقت معماری؛ انطباق V3.3.3 هنوز FAIL است.** این تصمیم مجوز استثنا یا ادعای تکمیل T4 نیست.

متن [ASVS 5.0.0، V3.3.3](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x12-V3-Web-Frontend-Security.md#v33-cookie-setup) پیشوند `__Host-` را برای کوکی‌ها الزام می‌کند مگر آن‌که کوکی عمداً میان میزبان‌ها مشترک باشد. کوکی Refresh ما میان میزبان‌ها مشترک نیست. `__Host-` به `Secure`، نبود `Domain` و `Path=/` نیاز دارد؛ بنابراین با مسیر محدود `/api/auth` جمع نمی‌شود.

| گزینه | مزیت | تهدید یا هزینه | تصمیم |
| --- | --- | --- | --- |
| `__Secure-tg_refresh` با `Path=/api/auth` روی میزبان فعلی | مرورگر کوکی را فقط برای endpointهای Auth می‌فرستد؛ HTTP-only، Secure و SameSite=Strict برقرار است | پیشوند Host ندارد؛ برنامهٔ دیگری روی همان host می‌تواند برای مسیر Auth کوکی هم‌نام با Path یا Domain متفاوت ایجاد کند؛ سرور باید تکرار/ابهام را رد کند | **وضعیت فعلی موقت**؛ V3.3.3 باز می‌ماند |
| مبدأ/میزبان اختصاصی Auth با `__Host-` و `Path=/` | مرز host برای کوکی برقرار و دامنهٔ ارسال آن فقط همان مبدأ Auth است؛ الزام ASVS قابل آزمون می‌شود | تغییر قرارداد Web proxy، CORS/Origin، CSRF، redirect، TLS، استقرار مشتری و تست مرورگر؛ روی همان host اصلی با `Path=/` پذیرفته نیست | **راهکار هدف** پس از طراحی و آزمون استقرار |
| استثنای معماری با کوکی مسیر محدود | تغییر مسیر استقرار لازم ندارد | همچنان V3.3.3 را نقض می‌کند؛ کنترل جبرانی جای ادعای PASS را نمی‌گیرد | فقط با مالک، دامنه، خطر، کنترل، آزمون، تاریخ انقضا و تأیید رسمی قابل طرح است؛ هنوز تأیید نشده است |

کنترل‌های فعلی: refresh و logout فقط با Origin مجاز، SameSite=Strict، HttpOnly، Secure، مسیر محدود و گردش اتمی توکن کار می‌کنند. Access Token در حافظهٔ رابط نگه داشته می‌شود. این کنترل‌ها احتمال CSRF و ارسال ناخواستهٔ کوکی را کم می‌کنند، اما cookie tossing یا تداخل برنامه‌های هم‌میزبان را به‌طور کامل منتفی نمی‌کنند. مرورگر و gateway نیز باید رد کوکی‌های تکراری با نام یکسان را آزمون کنند؛ این آزمون هنوز ثبت نشده است.

قبل از PASS کردن V3.3.3 باید مبدأ اختصاصی Auth، کوکی `__Host-` با `Path=/` فقط روی همان مبدأ، Origin/CORS/CSRF، logout/refresh/replay و تصویر مشتری به‌صورت مرورگری و عملیاتی آزموده شوند. تا آن زمان `READY_FOR_RAG_SECURITY_GATE = NO`.
