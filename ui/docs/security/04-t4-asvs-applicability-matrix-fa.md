# ماتریس کاربردپذیری و شواهد ASVS 5.0.0 سطح ۳ برای T4

**تاریخ بازبینی: ۲۰۲۶-۱۰-۰۳. وضعیت T4: PARTIAL. دروازهٔ RAG: NO.** این ماتریس تصمیم مهندسی دربارهٔ محصول هدف فعلی است و گواهی انطباق یا مجوز انتشار Auth نیست. متن و نتیجهٔ تک‌تک ۳۴۵ الزام در `reports/security/asvs-5.0-l3.json` ثبت شده است.

## روش و مرز بررسی

مرز شامل Web/SvelteKit، API، Worker، PostgreSQL، CJSON و secretRef، AI Router، Admission، Audit/SIEM، فایل‌های ابزار عمومی، قفل runtime و تصویر customer است. موجودی ماشین‌خوان `reports/security/t4-target-scope-inventory.json` مسیرهای HTTP، SSE، فایل، خروجی شبکه، پروتکل‌های غایب، رمزنگاری و زنجیرهٔ تأمین را ثبت می‌کند. نبود شرط فنی مشخص با دلیل مختص همان کنترل N/A شده است. کنترل دارای کد/آزمون کافی PASS، نقص مشاهده‌شده FAIL، و کنترل قابل‌اعمال بدون شاهد کافی NOT_VERIFIED است. حکم فصل‌محور صادر نشده است.

آزمون‌های موجود شامل واحد، PostgreSQL/HTTP زنده، Chrome، معماری و تصویر API مشتری C است. شواهد تصویر Web/Worker با Auth فعال، edge تولید، TLS، زمان‌همگام‌سازی، اسکن آسیب‌پذیری فعلی و بعضی آزمون‌های بدخواهانه هنوز فراهم نیست. تلاش `npm audit` در محیط محدود شبکه کامل نشد؛ تلاش دوم برای ارسال فرادادهٔ وابستگی به npm registry در بازبینی خودکار مجوز رد شد. بنابراین نتیجهٔ اسکن «نامشخص» است. متغیر محیطی `NODE_TLS_REJECT_UNAUTHORIZED=0` در تلاش اولیه نیز آن را برای شاهد امنیتی نامعتبر می‌کرد.
